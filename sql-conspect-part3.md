# Конспект — часть 3: выражения в SELECT и встроенные функции

---

## 1. Что может быть выражением после SELECT

Список выражений после `SELECT` — это набор выражений, разделённых запятыми. В качестве выражения могут использоваться:

| Выражение | Пример |
|---|---|
| **Столбец** | `SELECT doctor_num FROM doctors;` |
| **Константа** | `SELECT 5 FROM doctors;`<br>`SELECT 'Привет' FROM doctors;` |
| **Операция над выражениями** | `SELECT cabinet_num + 1 FROM doctors;` |
| **Функция от выражения** | `SELECT CONCAT('г.', area_address) FROM med_area;` |

💡 То есть после `SELECT` необязательно писать только названия колонок — можно писать числа, текст, арифметику и вызовы функций, и для каждой строки таблицы это выражение посчитается заново.

---

## 2. Строковые и числовые функции

| Функция | Описание | Пример | Результат |
|---|---|---|---|
| `CONCAT(l1, l2, l3, ..., ln)` | Объединяет вместе два или более выражений | `SELECT CONCAT('П','р','и','в','е','т') AS ex_concat;` | `Привет` |
| `LOWER(строка)` | Преобразует все символы строки в строчные (нижний регистр) | `SELECT LOWER('ПриВет1234') AS ex_lower;` | `привет1234` |
| `UPPER(строка)` | Преобразует все символы строки в верхний регистр | `SELECT UPPER('ПриВет1234') AS ex_upper;` | `ПРИВЕТ1234` |
| `ABS(число)` | Возвращает абсолютное значение числа | `SELECT ABS(-12.36) AS ex_abs;` | `12.36` |
| `GREATEST(n1, n2, ..., n)` | Возвращает наибольшее значение в списке выражений | `SELECT GREATEST(8,9,23,45,78,2,13,75) AS ex_greatest;` | `78` |
| `LEAST(n1, n2, ..., n)` | Возвращает наименьшее значение в списке выражений | `SELECT LEAST(8,9,23,45,78,2,13,75) AS ex_least;` | `2` |
| `ROUND(число, [число_знаков])` | Округляет число до указанного кол-ва знаков после запятой (по умолчанию — до 0) | `SELECT ROUND(8.589) AS r1, ROUND(8.589, 2) AS r2;` | `9`, `8.59` |

### GREATEST vs MAX — важное отличие

Это разные вещи, их часто путают:

- **`GREATEST`** — сравнивает значения **в рамках одной строки** (по горизонтали, между колонками).
- **`MAX`** — сравнивает значения **в рамках одного столбца** (по вертикали, между разными строками; это агрегатная функция, используется с `GROUP BY` или без него для всей таблицы).

**Пример на таблице товаров:**

| Идентификатор | Код | Наименование | Цена, руб. | Количество | Поставщик |
|---|---|---|---|---|---|
| 1 | 000256 | Фен Philips | 4250 | 15 | 1 |
| 2 | 000365 | Смартфон A52 | 16895 | 24 | 2 |
| 3 | 004859 | Телевизор | 35600 | 8 | 2 |

```sql
-- GREATEST: сравнивает значения ВНУТРИ одной строки (например цену и количество)
SELECT GREATEST(цена, количество) FROM товары;

-- MAX: сравнивает значения ОДНОГО столбца между всеми строками
SELECT MAX(цена) FROM товары;  -- вернёт 35600 (цена телевизора)
```

💡 Проще запомнить так: `GREATEST` смотрит **→ вправо по строке**, `MAX` смотрит **↓ вниз по столбцу**.

## 3. Функции для работы с датами

| Функция | Описание | Пример | Результат |
|---|---|---|---|
| `CURDATE()` | Возвращает текущую дату | `SELECT CURDATE() AS ex_curdate;` | `2024-01-14` |
| `DAY(дата)` | Возвращает номер дня месяца из даты | `SELECT DAY('2024-01-14') AS ex_day;` | `14` |
| `MONTH(дата)` | Возвращает числовое значение месяца из даты | `SELECT MONTH('2024-01-14') AS ex_month;` | `1` |
| `YEAR(дата)` | Возвращает год из значения даты | `SELECT YEAR('2024-01-14') AS ex_year;` | `2024` |
| `DATEDIFF(дата1, дата2)` | Возвращает число дней между двумя датами. Если дата1 > дата2 — результат положительный, если дата1 < дата2 — отрицательный | `SELECT DATEDIFF('2024-01-14', '2023-11-12') AS ex_datediff;` | `63` |

**Пример практического применения** — узнать возраст пациента в днях на текущий момент:

```sql
SELECT lastname, name, DATEDIFF(CURDATE(), date_of_birth) AS дней_с_рождения
FROM patients;
```

## 4. Логические и проверочные функции

| Функция | Описание | Пример | Результат |
|---|---|---|---|
| `ISNULL(выражение)` | Проверяет, является ли выражение NULL. Возвращает `1`, если NULL, и `0`, если нет | `SELECT ISNULL(''), ISNULL(NULL), ISNULL('Привет');` | `0`, `1`, `0` |
| `IF(условие, значение_если_True, значение_если_False)` | Возвращает одно значение, если условие TRUE, и другое — если FALSE | `SELECT IF(50<100, 'y', 'n') AS ex_if;` | `y` |
| `COALESCE(выр1, выр2, ..., вырN)` | Возвращает первое НЕ NULL выражение в списке | `SELECT COALESCE(NULL, NULL, 'Привет', NULL, 'Пока') AS ex_coalesce;` | `Привет` |

⚠️ **Важный нюанс с `ISNULL`**: пустая строка `''` — это **не** то же самое, что `NULL`. `ISNULL('')` вернёт `0` (не NULL), потому что пустая строка — это всё-таки значение, просто пустое. А `ISNULL(NULL)` вернёт `1`.

**Пример практического применения `IF`** — подписать зарплату категорией:

```sql
SELECT lastname, salary,
       IF(salary >= 150000, 'Высокая', 'Обычная') AS категория_зп
FROM test;
```

**Пример практического применения `COALESCE`** — подставить значение по умолчанию, если поле пустое:

```sql
SELECT lastname, COALESCE(settled_in, 'Дата не указана') AS settled_in
FROM test;
```

💡 `COALESCE` особенно полезен, когда нужно "подстраховаться" от `NULL` в отчётах — вместо пустой ячейки показать понятный текст.
