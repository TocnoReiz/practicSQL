# Конспект — часть 2: INSERT, UPDATE, CONCAT, DELETE, TRUNCATE

---

## 1. INSERT — добавление данных

Команда `INSERT` добавляет новую(ые) строку(и) в таблицу.

**Синтаксис:**
```sql
INSERT INTO название_таблицы (колонка1, колонка2, колонка3)
VALUES (значение1, значение2, значение3);
```

**Пример:**
```sql
INSERT INTO test (lastname, name, title, salary, date_of_birth, settled_in)
VALUES ('Иванов', 'Иван', 'Программист', 150000, '2005-07-15', '2026-09-01');
```

**Добавление нескольких строк сразу:**
```sql
INSERT INTO departments (department_name)
VALUES 
    ('Разработка'),
    ('Бухгалтерия'),
    ('HR');
```

⚠️ **Частые ошибки:**
- Забыть запятую между значениями (строки "слипаются" в одну).
- Количество значений в `VALUES` должно строго совпадать с количеством колонок, указанных после `INTO`.

---

## 2. UPDATE + SET + WHERE — изменение данных

Команда `UPDATE` изменяет уже существующие строки.

**Синтаксис:**
```sql
UPDATE название_таблицы
SET колонка = новое_значение
WHERE условие;
```

- **SET** — обязательная часть, указывает какую колонку и на что менять.
- **WHERE** — указывает, **какие именно строки** нужно изменить. Если `WHERE` не указать — изменятся **ВСЕ строки таблицы**!

**Пример:**
```sql
UPDATE test
SET department_id = 1
WHERE name = 'Иван';
```

**Изменение нескольких колонок сразу:**
```sql
UPDATE test
SET salary = 180000, title = 'Senior Программист'
WHERE lastname = 'Иванов';
```

⚠️ **Важно:**
- Строковые значения — только в одинарных кавычках `'...'`. Двойные `"..."` — это названия колонок/таблиц, а не текст.
- Без `WHERE` — обновится вся таблица целиком. Это самая частая и опасная ошибка новичков.

---

## 3. CONCAT — склейка строк

Функция `CONCAT()` объединяет несколько строк в одну.

**Синтаксис:**
```sql
CONCAT(строка1, строка2, ...)
```

**Пример — добавить город в начало адреса для всех записей:**
```sql
UPDATE med_area
SET area_address = CONCAT('г. Москва, ', area_address);
```

Было: `ул. Ленина` → Стало: `г. Москва, ул. Ленина`

💡 `CONCAT` часто используют именно внутри `UPDATE ... SET`, потому что нужно взять **текущее** значение колонки и что-то к нему добавить.

---

## 4. DELETE — удаление строк

Команда `DELETE` удаляет строки из таблицы (сама таблица остаётся).

**Синтаксис:**
```sql
DELETE FROM название_таблицы
WHERE условие;
```

**Пример:**
```sql
DELETE FROM test
WHERE lastname = 'Иванов';
```

⚠️ **Важно:** без `WHERE` удалятся **все строки** таблицы:
```sql
DELETE FROM test;  -- удалит ВСЕ записи, таблица останется пустой
```

---

## 5. TRUNCATE — быстрая очистка таблицы

Команда `TRUNCATE` тоже удаляет все строки, но делает это иначе, чем `DELETE`.

**Синтаксис:**
```sql
TRUNCATE TABLE название_таблицы;
```

**Пример:**
```sql
TRUNCATE TABLE test;
```

### DELETE vs TRUNCATE — в чём разница

| | DELETE | TRUNCATE |
|---|---|---|
| Условие WHERE | можно использовать | нельзя, удаляет всё сразу |
| Скорость | медленнее (удаляет построчно) | быстрее (сбрасывает таблицу целиком) |
| Счётчик SERIAL/AUTO_INCREMENT | НЕ сбрасывается | сбрасывается на начало |
| Откат (ROLLBACK) | можно откатить в транзакции | зависит от СУБД (в PostgreSQL можно) |

💡 Проще говоря: если нужно удалить **часть** данных — используй `DELETE ... WHERE`. Если нужно **полностью очистить** таблицу и по-быстрому — используй `TRUNCATE`.

---

## Шпаргалка одной строкой

```sql
INSERT INTO таблица (кол1, кол2) VALUES (знач1, знач2);
UPDATE таблица SET колонка = значение WHERE условие;
SELECT CONCAT(строка1, строка2);
DELETE FROM таблица WHERE условие;
TRUNCATE TABLE таблица;
```
