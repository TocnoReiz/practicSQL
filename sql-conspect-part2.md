# Конспект — часть 2: SELECT, INSERT, UPDATE, CONCAT, DELETE, TRUNCATE

---

## 1. SELECT — полная структура запроса выборки

Полный синтаксис (порядок блоков строгий, но не все обязательны):

```sql
SELECT список_колонок
FROM название_таблицы
[WHERE условие [AND | OR | NOT ...]]
[GROUP BY список_группировки]
[HAVING условие]
[ORDER BY список_сортировки [ASC | DESC]]
[LIMIT количество_строк];
```

Разберём каждый блок по порядку.

### WHERE — фильтрация строк

Отбирает строки **до** группировки, по условию.

```sql
SELECT * FROM doctors
WHERE salary > 100000;
```

**AND / OR / NOT:**

```sql
-- И то, и другое условие должно быть true
SELECT * FROM doctors
WHERE salary > 100000 AND title = 'Хирург';

-- Любое из условий
SELECT * FROM doctors
WHERE title = 'Хирург' OR title = 'Терапевт';

-- Отрицание условия
SELECT * FROM doctors
WHERE NOT title = 'Хирург';
-- то же самое, что title <> 'Хирург'
```

### Операторы сравнения и отбора

| Оператор | Что делает | Пример |
|---|---|---|
| `=`, `<>` (или `!=`) | равно / не равно | `WHERE title = 'Хирург'` |
| `>`, `<`, `>=`, `<=` | больше/меньше | `WHERE salary >= 100000` |
| `+`, `-`, `*`, `/` | арифметика (можно прямо в SELECT) | `SELECT salary + 5000 FROM doctors` |
| `BETWEEN ... AND ...` | значение в диапазоне (включительно) | `WHERE salary BETWEEN 100000 AND 200000` |
| `IN (...)` | значение входит в список | `WHERE title IN ('Хирург', 'Терапевт')` |
| `LIKE` | поиск по шаблону (`%` — любые символы, `_` — один символ) | `WHERE name LIKE 'А%'` |
| `IS NULL` / `IS NOT NULL` | проверка на пустое значение | `WHERE settled_in IS NULL` |

**Пример с BETWEEN и IN вместе:**

```sql
SELECT * FROM doctors
WHERE salary BETWEEN 100000 AND 200000
  AND title IN ('Хирург', 'Терапевт', 'Кардиолог');
```

💡 `BETWEEN 100000 AND 200000` — это то же самое, что `salary >= 100000 AND salary <= 200000`, просто короче.

💡 `IN ('А', 'Б', 'В')` — то же самое, что `title = 'А' OR title = 'Б' OR title = 'В'`, но короче и читабельнее.

### GROUP BY — группировка строк

Объединяет строки с одинаковым значением в указанной колонке в одну группу — обычно используется вместе с агрегатными функциями (`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`).

```sql
SELECT title, COUNT(*) AS кол_во_врачей
FROM doctors
GROUP BY title;
```

Результат — по одной строке на каждую уникальную должность (`title`) с количеством врачей в ней.

### HAVING — фильтрация после группировки

`WHERE` фильтрует строки **до** группировки, а `HAVING` — **группы после** группировки. `HAVING` нужен, если условие завязано на агрегатную функцию (`COUNT`, `SUM` и т.д.) — в `WHERE` так писать нельзя.

```sql
SELECT title, COUNT(*) AS кол_во_врачей
FROM doctors
GROUP BY title
HAVING COUNT(*) > 5;
```

Покажет только те должности, где врачей больше 5.

**WHERE + GROUP BY + HAVING вместе:**

```sql
SELECT title, AVG(salary) AS средняя_зарплата
FROM doctors
WHERE salary > 50000        -- фильтруем строки ДО группировки
GROUP BY title
HAVING AVG(salary) > 120000; -- фильтруем группы ПОСЛЕ группировки
```

### ORDER BY — сортировка результата

```sql
SELECT * FROM doctors
ORDER BY salary DESC;  -- по убыванию (от большего к меньшему)

SELECT * FROM doctors
ORDER BY lastname ASC;  -- по возрастанию (по умолчанию, можно не писать)
```

Можно сортировать по нескольким колонкам:

```sql
SELECT * FROM doctors
ORDER BY title ASC, salary DESC;
-- сначала группируем по алфавиту должностей, внутри каждой — по убыванию зарплаты
```

### LIMIT — ограничение количества строк

```sql
SELECT * FROM doctors
ORDER BY salary DESC
LIMIT 5;  -- покажет только топ-5 самых высокооплачиваемых
```

---

### Полный пример со всеми блоками вместе

```sql
SELECT title, COUNT(*) AS кол_во, AVG(salary) AS средняя_зп
FROM doctors
WHERE salary BETWEEN 50000 AND 300000
GROUP BY title
HAVING COUNT(*) >= 2
ORDER BY средняя_зп DESC
LIMIT 3;
```

Что делает: берёт врачей с зарплатой от 50 000 до 300 000 → группирует по должности → оставляет только те должности, где 2 и больше врачей → сортирует по средней зарплате (от большей к меньшей) → показывает топ-3.

⚠️ **Порядок выполнения важно понимать** (он отличается от порядка написания в коде):
1. `FROM` — берём таблицу
2. `WHERE` — фильтруем строки
3. `GROUP BY` — группируем
4. `HAVING` — фильтруем группы
5. `SELECT` — выбираем колонки
6. `ORDER BY` — сортируем
7. `LIMIT` — обрезаем количество

## 2. INSERT — добавление данных

Команда `INSERT` добавляет новую(ые) строку(и) в таблицу.

**Синтаксис:**
```sql
INSERT INTO название_таблицы (колонка1, колонка2, колонка3)
VALUES (значение1, значение2, значение3);
```

**Пример:**
```sql
INSERT INTO test (lastname, name, title, salary, date_of_birth, settled_in)
VALUES ('Иванов', 'Иван', 'Программист', 150000, '2005-07-15', '2026-09-01');
```

**Добавление нескольких строк сразу:**
```sql
INSERT INTO departments (department_name)
VALUES 
    ('Разработка'),
    ('Бухгалтерия'),
    ('HR');
```

⚠️ **Частые ошибки:**
- Забыть запятую между значениями (строки "слипаются" в одну).
- Количество значений в `VALUES` должно строго совпадать с количеством колонок, указанных после `INTO`.

## 3. UPDATE + SET + WHERE — изменение данных

Команда `UPDATE` изменяет уже существующие строки.

**Синтаксис:**
```sql
UPDATE название_таблицы
SET колонка = новое_значение
WHERE условие;
```

- **SET** — обязательная часть, указывает какую колонку и на что менять.
- **WHERE** — указывает, **какие именно строки** нужно изменить. Если `WHERE` не указать — изменятся **ВСЕ строки таблицы**!

**Пример:**
```sql
UPDATE test
SET department_id = 1
WHERE name = 'Иван';
```

**Изменение нескольких колонок сразу:**
```sql
UPDATE test
SET salary = 180000, title = 'Senior Программист'
WHERE lastname = 'Иванов';
```

⚠️ **Важно:**
- Строковые значения — только в одинарных кавычках `'...'`. Двойные `"..."` — это названия колонок/таблиц, а не текст.
- Без `WHERE` — обновится вся таблица целиком. Это самая частая и опасная ошибка новичков.

## 4. CONCAT — склейка строк

Функция `CONCAT()` объединяет несколько строк в одну.

**Синтаксис:**
```sql
CONCAT(строка1, строка2, ...)
```

**Пример — добавить город в начало адреса для всех записей:**
```sql
UPDATE med_area
SET area_address = CONCAT('г. Москва, ', area_address);
```

Было: `ул. Ленина` → Стало: `г. Москва, ул. Ленина`

💡 `CONCAT` часто используют именно внутри `UPDATE ... SET`, потому что нужно взять **текущее** значение колонки и что-то к нему добавить.

## 5. DELETE — удаление строк

Команда `DELETE` удаляет строки из таблицы (сама таблица остаётся).

**Синтаксис:**
```sql
DELETE FROM название_таблицы
WHERE условие;
```

**Пример:**
```sql
DELETE FROM test
WHERE lastname = 'Иванов';
```

⚠️ **Важно:** без `WHERE` удалятся **все строки** таблицы:
```sql
DELETE FROM test;  -- удалит ВСЕ записи, таблица останется пустой
```

---

## 6. TRUNCATE — быстрая очистка таблицы

Команда `TRUNCATE` тоже удаляет все строки, но делает это иначе, чем `DELETE`.

**Синтаксис:**
```sql
TRUNCATE TABLE название_таблицы;
```

**Пример:**
```sql
TRUNCATE TABLE test;
```

### DELETE vs TRUNCATE — в чём разница

| | DELETE | TRUNCATE |
|---|---|---|
| Условие WHERE | можно использовать | нельзя, удаляет всё сразу |
| Скорость | медленнее (удаляет построчно) | быстрее (сбрасывает таблицу целиком) |
| Счётчик SERIAL/AUTO_INCREMENT | НЕ сбрасывается | сбрасывается на начало |
| Откат (ROLLBACK) | можно откатить в транзакции | зависит от СУБД (в PostgreSQL можно) |

💡 Проще говоря: если нужно удалить **часть** данных — используй `DELETE ... WHERE`. Если нужно **полностью очистить** таблицу и по-быстрому — используй `TRUNCATE`.

## Шпаргалка одной строкой

```sql
SELECT колонки FROM таблица WHERE условие GROUP BY колонка HAVING условие ORDER BY колонка ASC|DESC LIMIT n;
INSERT INTO таблица (кол1, кол2) VALUES (знач1, знач2);
UPDATE таблица SET колонка = значение WHERE условие;
SELECT CONCAT(строка1, строка2);
DELETE FROM таблица WHERE условие;
TRUNCATE TABLE таблица;
```
